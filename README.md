# Mulrules-evaluation
## Introduction
This repository serves as a supplementary resource for a master's thesis investigating the combination of various local rule-based explainers. The motivation stems from comparative analyses presented in the original literature on explanation methods. While most studies focus on demonstrating that a particular method outperforms or dominates others, this project aims to empirically assess the differences between explanations generated by different methods. Furthermore, it proposes a framework for selecting explanations that best align with user-defined criteria combining simple filters (tresholds, correctness) with domination relation filtering and MCDA ideal point selection method .

## Results

The results of the experiments can be found in the **"Final Experiment"** folder. This folder contains both Jupyter notebooks and HTML versions of the experiment reports.  

> **Note:** Both formats require additional steps to be displayed correctly:  
> - **Jupyter Notebooks:** Use the corresponding environment or an online viewer (e.g., [NBViewer](https://nbviewer.org/)).  
> - **HTML Reports:** Download and open directly in a web browser.  

The results are organized into **six experiments** (each corresponding to a dataset + model combination) and **two types of reports**:  
- `Results_Generalized`: Generalized measures aggregated over all rules.  
- `Results`: Complete details of all rules for each explained instance.  

---

## Experiments Reproduction

To reproduce the experiments:  
1. Clone the repository and install the required packages.  
2. Open `run_experiments.py`. Uncomment and modify the values of `experiment_name` and `classifiers_names` to select the desired experiment (dataset + model combination).  
3. Run the script. The results will be saved in the `experiments_log` folder (located in the root directory).  
4. Copy any notebook (`Results_Generalized` or `Results`) from the **"Final Experiment"** folder to the root directory (next to `run_experiments.py`) and replace the log filenames with the newly generated ones.

## Further Experiments

To add a new dataset or modify explainer or black box parameters:  
- Edit the corresponding lines in `run_experiments.py`.  
- Add the dataset to the **data** folder, if necessary.  

Introducing new explainers or black boxes requires additional modifications, such as:  
- Creating a wrapper for the new explainer.  
- Extending `classifier.py` to accommodate new models.

## Known Issues

- LORE exhibits slow performance.  
- Parallel runs may experience reduced performance.  
- Occasional errors occur during explanation generation for specific instances.  
- Critical errors may arise when using LORE and LORE-SA interchangeably, likely due to changes in default parameters in certain packages.
